# UltraBench: Executable Benchmark for Endurance-Training Agents

**UltraBench** is an executable multi-turn benchmark for CLI-based endurance-training agents introduced in [**Switchback: A Long-Horizon Agent System for Ultrarunning Training**](https://switchback.run/#paper) (NeurIPS 2026 Workshop on GenAI for Health: Agentic Systems, Clinical Trust, and Future Potential).

It evaluates the same native CLI and underlying foundation model under two paired conditions:
- **Baseline CLI agent (`cli_agent`):** `Help this athlete make well-grounded endurance-training decisions. Use available files and tools when relevant.`
- **Switchback (`switchback`):** The same workspace and MCP environment augmented with the Switchback specification (`COMPANION.md`), athlete-owned memory conventions, selective domain knowledge chapters, and reusable workflow skills.

## Benchmark Split & Anti-Contamination Policy

UltraBench comprises 60 multi-turn synthetic scenarios across three primary strata (`safety_and_adaptation`, `constructive_planning`, and `agent_operations`):
- **`UltraBench-Dev` (`D01`–`D12`, 12 scenarios — Public):** Included in [`scenarios_dev.json`](scenarios_dev.json) and hosted publicly at [`hf.co/datasets/rlacombe/ultrabench`](https://huggingface.co/datasets/rlacombe/ultrabench) for local development, prompt/harness iteration, and debugging.
- **`UltraBench-Test` (`T01`–`T48`, 48 scenarios — Held-Out Private):** Withheld from public release to prevent training-data contamination and benchmark overfitting.

All athlete profiles, training histories, wellness records, and MCP payloads are 100% deterministic synthetic fixtures generated by [`synthetic_data.py`](synthetic_data.py); no real athlete data is used.

## Running UltraBench-Dev Locally

1. Install dependencies:
   ```bash
   pip install -r evals/requirements.txt
   ```
2. Run a paired evaluation on the 12 public `UltraBench-Dev` scenarios (`scenarios_dev.json`):
   ```bash
   python evals/run_native_replays.py \
     --harness agy \
     --model gemini-3.8-flash-medium \
     --dataset evals/scenarios_dev.json \
     --output /tmp/ultrabench-dev-run
   ```
3. Score completed trajectories with the blinded three-judge panel:
   ```bash
   python evals/judge_cli_results.py /tmp/ultrabench-dev-run/results.json \
     --dataset evals/scenarios_dev.json
   ```
